# AITrain Studio 用户使用手册

## 开始工作

启动时先完成离线授权验证。没有有效注册码时，复制机器码交给授权方，再输入签发的注册码。授权绑定当前机器。

进入工作台后可打开最近项目、打开其他项目或新建项目。项目集中保存数据版本、任务记录、模型和报告。项目菜单始终位于顶栏；重建项目属于管理操作，会清除项目内部元数据与已提交产物，操作前界面会说明范围并确认。

日常导航只有三个入口：

| 入口 | 用途 |
|---|---|
| 数据集 | 导入、查看样本与版本、质量检查、转换、划分、标注和复核 |
| 训练 | 查看训练记录、配置训练、监控运行和读取日志 |
| 模型 | 模型目录、导入、验证与交付、验收报告 |

顶栏的任务记录汇总所有任务。环境与诊断、设置位于工具区。进入工具后可返回之前的工作区。

## 检查环境

在环境与诊断页面点击“检查环境”。检查结果来自独立 Worker；未检查、缺失依赖、警告和通过分别显示。修改 Python 或运行环境后，应重新检查。

YOLO、SMP、Anomalib 与 PaddleOCR 使用各自的官方后端和环境配置。GPU 训练需要对应框架的 GPU 版本；仅安装 CPU 版本不能使用 GPU 设备号。环境页的诊断包入口可收集检查结果、驱动信息和最近任务信息。

ONNX Runtime、NCNN 和 TensorRT 的产品支持状态与本机依赖是否齐全是不同条件。界面只列出当前模型与本机共同允许执行的路线；具体边界见本文最后一节。

## 导入和查看数据

1. 在数据集目录点击“导入数据”。
2. 选择来源、填写名称并确认格式。来源可按当前导入合同选择目录或文件。
3. 点击导入。完成后目录会选中新登记的数据版本。
4. 点击“查看样本”，选择图像查看预览；通过版本选择器查看其他已提交版本。

数据集名称用于识别对象。版本、快照和产物身份由系统绑定，不需要填写多组 ID。样本预览按需读取；不支持或超过预览限制的图像会显示原因。图像文件数量、训练样本数量和快照全部文件数量可能不同；未完成统计时显示“未统计”。

目录提供上一页和下一页。未知总数量时不显示虚构页数。查看详情后返回目录，会保留当前选择。

## 检查质量、划分与转换

选中数据集后从“更多操作”进入质量检查、导入新版本、数据划分、修复与标注、样本复核或技术详情。

质量检查使用当前选中的数据版本，完成后显示问题列表及报告。质量报告与版本一一对应；切换版本后不会沿用另一个版本的报告。未运行质量检查不被界面额外设为训练硬性门槛，实际要求以对应工作流校验为准。

划分数据需要填写目标名称和比例，结果作为新的已提交对象登记。格式转换使用来源路径与受支持的格式组合，结果完成后进入数据目录。它保留现有转换边界，不是任意快照之间的无损转换承诺。

修复与标注使用外部标注会话：选择修复清单、工作目录和工具，完成标注后选择会话同步结果。界面没有新增内置标注绘制编辑器。样本复核只读取项目内已提交报告和安全成员。

## 配置训练

可从选中数据集点击“用于训练”，也可在训练目录点击“新建训练”。

先选择数据版本；交付检查需要样本时，选择同一版本中的图像。任务与算法选项来自支持该数据格式的官方后端。模型、轮数、批次、输入尺寸和设备沿用现有后端约定；EfficientAD 的训练批次固定为 1。PaddleOCR 的其他参数由所选官方配置决定。

高级参数在独立编辑视图中按组显示。点击应用后保留修改，点击取消修改则恢复进入编辑器前的内容。基础字段会检查数值格式，后端仍会执行自身约束校验。

切换日常页面会保留当前训练草稿。仅浏览其他数据集不会替换训练绑定；需要显式点击“用于训练”或选择新的数据版本。草稿按项目自动保存到当前 Windows 用户的应用设置中，也可点击“保存草稿”。重启后重新进入该项目的训练配置即可恢复；未应用的高级编辑不会写入草稿。

恢复时会核对项目身份、完整数据版本绑定和样本成员。已失效的数据或样本会提示重新选择；损坏或不支持版本的草稿保留默认参数。“丢弃草稿”在确认后清除本项目草稿并恢复默认参数。移动项目不会改变其草稿身份，重建项目会生成新身份并隔离旧草稿。草稿只恢复编辑配置，不自动启动或续训。

点击开始训练后进入监控。进度、曲线和指标只展示实际收到的数据；没有返回的指标显示尚未提供。取消请求发出后需要等待 Worker 返回终态。当前版本不提供断点续训。

训练目录可继续载入更早记录，并显示来源数据版本和模型。打开历史训练后，可查看已保存配置，或点击“复制配置新建训练”恢复为新的草稿；系统重新核对原数据版本，交付检查样本需要重新选择。复制不会启动任务，也不是断点续训。

历史训练的完整日志及已提交文件从对应任务详情查看；当前训练提供最新日志和完整日志阅读模式。模型登记完成后，“查看模型”直接打开该次训练生成的模型。

## 模型与验证

模型目录显示名称、任务、来源、格式和最近独立验证状态。模型合同校验在详情中单独展示；合同有效和验证流程完成都不等于客户场景精度通过。

查看详情可追溯来源任务和报告。导入模型需要模型文件与相匹配的模型说明 JSON。说明编辑器可检查和调整已有模型语义，完整说明入口保留输入输出张量、来源快照、预处理与类别等字段。系统不会猜测模型语义或自动生成精度结论。

从模型点击“验证与交付”，选择可执行路线，再选择已提交数据版本中的样本。一次操作会执行现有的模型解析、校验、推理、计时、部署检查和交付报告流程。完成后显示实际可视化结果和报告入口；失败时可查看对应任务。样本计时只描述本次运行，不代表性能 SLA。

## 任务记录与报告

任务记录提供状态筛选、在已载入记录中查找、载入更多和任务详情。详情通过一个内容选择器切换产物目录、文件、指标、工作流与预览。

先选择产物，再查看其文件清单，最后选择文件预览。未读取清单时不会显示“0 个文件”。报告和图像读取经过项目身份及成员校验；普通页面不提供绕过项目登记直接打开产物物理目录的入口。

## 验收报告与 OCR

模型页的“验收报告”入口提供报告目录、官方 OCR 报告导入、OCR 验收及外部验收结果导入。

导入 OCR 报告时，分别选择 Det、Rec、System 官方 JSON，并为每份绑定数据版本，填写验收批次、客户域和证据分类。运行验收时选择三份已提交报告并设置阈值，不需要填写产物 ID。

报告目录分别展示运行状态和证据校验状态。公开数据、生成数据和 smoke 只证明对应流程，不能替代客户域精度证据。诊断包和外部验收报告同样按实际返回结果展示。

## 设置与当前范围

设置包含内置能力摘要、默认项目位置、语言偏好、外观主题和许可信息。浅色、深色主题切换立即生效，重启后保留。中英文语言偏好保存后需要重启；英文资源覆盖工作台操作、表单和状态文案。用户命名、模型标识及原始后端日志保留原文。

数据集、模型、训练记录、任务和验收报告目录均可搜索整个当前项目；输入后稍候或按回车执行。搜索结果先按条件匹配，再按游标分页，改变搜索条件会重新从第一页开始。数据集搜索名称和格式；模型搜索模型族、任务、来源和日期；训练与任务搜索后端和已保存配置；报告搜索登记类别、任务和文件名。报告正文与用户文件内容不属于目录搜索范围。

当前八个正式训练后端为 Ultralytics YOLO 检测、实例分割和旋转框检测，SMP 语义分割，Anomalib PatchCore 和 EfficientAD，PaddleOCR Det 和 Rec 官方适配器。

- YOLO 检测和实例分割使用官方训练、首次 ONNX 导出与评估；受支持的打包推理、计时和部署验证由 AITrain C++ 运行时执行。
- OBB 与 SMP 当前产品部署使用 ONNX Runtime。SMP 不提供 NCNN / TensorRT 导出。
- 异常检测使用 Worker 管理的 Python / Anomalib 产物，不声明 C++ ONNX / NCNN / TensorRT 异常检测推理。
- OCR 验收使用 PaddleOCR 官方报告。
- TensorRT 导出入口保留；当前 TensorRT 推理解码器未实现，界面不会将其列为可执行交付路线。

界面改造不新增算法、Schema 12 迁移、Resume、客户域精度证明、Clean Windows 验收或 package-root TensorRT 复验证据。
