# ADR-002：V2 模块依赖方向

日期：2026-07-15  
状态：已接受

## 决策

V2 采用单向依赖：`Domain -> Protocol/Storage -> Application -> Worker Host 或 GUI Presenter`。Domain 只依赖 QtCore；Storage 不依赖 GUI、运行时 SDK 或 Python；Presenter 不直接写数据库。

## 后果

- `aitrain_v2_domain` 可独立测试状态和失败分类。
- `aitrain_v2_protocol` 与 `aitrain_v2_storage` 可被 Worker、GUI 和测试共同使用。
- 旧 `MainWindow`、`WorkerClient` 与 `ProjectRepository` 的耦合将在后续迁移中删除，而不是复制到 V2。
