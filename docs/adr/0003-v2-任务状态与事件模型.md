# ADR-003：V2 任务状态与事件模型

日期：2026-07-15  
状态：已接受

## 决策

任务状态固定为 `created -> queued -> starting -> running -> succeeded|failed`，取消通过 `cancel_requested -> canceled` 表示。状态转换由 Domain 判定，Storage 使用 compare-and-swap 更新状态并追加事件。每个协议消息必须拥有 UUID 的 `messageId`、`requestId`、`taskId` 和严格递增 sequence。

## 后果

- Worker、GUI 和进程退出不能各自写终态。
- 重复终态只允许相同终态幂等；乱序、重复和跨任务消息必须拒绝。
- 应用重启时未终态任务标记为 `failed/process_crashed`。
